# Tienda Don Pedro

Proyecto de inventario de la Tienda Don Pedro, realizado con Git, GitHub y Python.

## Productos

| Producto | Precio |
|---|---:|
| Leche 1L | $4.500 |
| Pan tajado | $6.500 |
| Huevos x12 | $14.000 |
| Café 500g | $18.000 |
| Panela | $3.500 |
| Arroz 1kg | $4.500 |

## Estructura del proyecto

* datos/: productos, clientes y ventas.
* src/: programa principal de Python.
* .gitignore: archivos que no deben subirse al repositorio.

## Ejecutar el programa

python src/main.py

Proyecto de inventario de la Tienda Don Pedro, realizado con Git, GitHub y Python.

## **Domicilios**

La tienda ofrece servicio de domicilios para que puedas recibir tus productos en la comodidad de tu hogar.

- **Horario:** Lunes a sábado, de 8:00 a. m. a 7:00 p. m.
- **Barrio que cubre:** Laureles y sectores cercanos.
- **Tiempo estimado de entrega:** Entre 30 y 45 minutos.
- **Costo del domicilio:** $3.000 COP.

**Nota:** Los horarios, la cobertura y las tarifas son datos ficticios de ejemplo.

## Estructura del proyecto

* datos/: productos, clientes y ventas.
* src/: programa principal de Python.
* .gitignore: archivos que no deben subirse al repositorio.

## Ejecutar el programa

python src/main.py
